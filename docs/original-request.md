# 12. برنامه زمان‌بندی

چون کامپیوتر ویندوز روزانه فقط چند ساعت روشن است، سیستم باید دو روش اجرا داشته باشد.

## اجرای محلی

با Windows Task Scheduler یا سرویس مناسب:

- هنگام روشن شدن سیستم
- هنگام ورود کاربر
- با اجرای دستی

داده‌ها به‌روزرسانی شوند.

اگر تحلیل روزانه انجام نشده، سیستم تلاش کند آن را اجرا کند.

از اجرای تکراری یک تحلیل جلوگیری کن.

## اجرای ابری رایگان

از GitHub Actions Scheduled Workflow استفاده کن.

- زمان‌بندی بر اساس UTC با تبدیل صحیح به Asia/Tehran
- بررسی روز معاملاتی
- اجرای تحلیل پس از پایان معاملات
- ثبت نتایج در Supabase
- ارسال گزارش تلگرام
- ثبت وضعیت موفقیت یا شکست

در نظر بگیر که اجرای زمان‌بندی‌شده GitHub Actions تضمین زمانی ندارد.

اگر اجرا انجام نشد، وضعیت گزارش باید مشخص باشد.

در صورت نیاز امکان اجرای دستی Workflow وجود داشته باشد.

هیچ‌وقت گزارش قدیمی را به‌عنوان گزارش امروز نمایش نده.
